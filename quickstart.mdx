This guide walks you through upscaling a single image from start to finish. By the end you will have a working output file and understand the core settings you will use every time you run QualityScaler.

<Steps>
  <Step title="Launch the app">
    Open `QualityScaler.exe` (or run `QualityScaler.py` if you are running from source). The main window opens with a file drop area on the left and all settings on the right.
  </Step>
  <Step title="Load your image">
    Click **SELECT FILES** in the left panel and choose one or more image files. QualityScaler supports JPG, JPEG, PNG, WEBP, HEIC, BMP, TIFF, and GIF.

    Once loaded, a preview of each file and its current resolution appears in the panel.
  </Step>
  <Step title="Choose an AI model">
    Use the **AI model** dropdown to select the model that best matches your content:

    | Model | Best for |
    |-------|----------|
    | `BSRGANx4` | High-quality photo upscaling (4x) |
    | `BSRGANx2` | High-quality photo upscaling (2x) |
    | `RealESRGANx4` | High-quality image upscaling (4x) |
    | `RealESR_Gx4` | Animated or degraded live-action video |
    | `RealESR_Ax4` | Animated or degraded live-action video |
    | `MSharpx4` | Image upscaling and sharpening (good-quality photos) |
    | `LVAx2` | Live-action video upscaling (2x) |
    | `IRCNN_Mx1` | Image and video de-noising |
    | `IRCNN_Lx1` | Image and video de-noising (strong) |

    For a first test with a photo, **BSRGANx4** is a good default.

    <Tip>
      Choosing the right model makes a significant difference in output quality. See [AI models](/guides/ai-models) for a full breakdown of each model's strengths, recommended blending settings, and VRAM usage.
    </Tip>
  </Step>
  <Step title="Set input and output resolution">
    Leave **Input Resolution %** at `100` and **Output Resolution %** at `100` for a standard full-resolution upscale. These values scale the image before and after AI processing respectively, and are useful when you want to target a specific output size.
  </Step>
  <Step title="Select a GPU">
    Use the **GPU** dropdown to choose your graphics card. Select **Auto** to let QualityScaler pick the best available device automatically. If you have multiple GPUs, you can select a specific one (GPU 1, GPU 2, etc.).
  </Step>
  <Step title="Click UPSCALE">
    Click the **UPSCALE** button to start processing. A progress indicator appears while the model runs. For images, processing typically takes a few seconds per file depending on your GPU and the image resolution.
  </Step>
  <Step title="Find your output file">
    By default, QualityScaler saves the output file to the same folder as the input. The output filename follows this pattern:

    ```text
    <original_name>_<AI_model>_InputR-100_OutputR-100.png
    ```

    For example, upscaling `photo.jpg` with `BSRGANx4` at default settings produces:

    ```text
    photo_BSRGANx4_InputR-100_OutputR-100.png
    ```

    The output format defaults to `.png`. You can change the image extension in the output settings.
  </Step>
</Steps>

<Note>
  If QualityScaler reports that the AI model file is missing, make sure you have downloaded the `.onnx` model files and placed them in the `/AI-onnx` folder. See [Installation](/installation) for details.
</Note>
