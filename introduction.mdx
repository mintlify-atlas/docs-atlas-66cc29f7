QualityScaler is a Windows desktop application that uses AI-powered deep learning models to upscale, enhance, and de-noise photographs and videos. It runs entirely on your PC — no cloud account, no subscription, and no internet connection required at any point.

## How it is built

QualityScaler is written entirely in Python. The key libraries are:

- **onnxruntime-directml** — runs ONNX AI models with DirectX 12 GPU acceleration
- **customtkinter** — provides the Windows 11-style GUI
- **OpenCV** (`opencv-python-headless`) — handles image and video frame processing
- **Pillow** — image loading and format conversion
- **ffmpeg** — video frame extraction and hardware-accelerated encoding

The AI models are distributed as `.onnx` files and loaded at runtime. They are downloaded separately and placed in the `/AI-onnx` folder alongside the application.

## Privacy

QualityScaler is fully offline. It does not make any network requests during installation or normal use. All AI inference runs locally on your GPU using DirectML. No usage data, telemetry, or image content is ever transmitted.
